# ESP32 Learning Projects

## English

This repository contains the small projects and tests I built while learning ESP32.
Before starting ESP32, I already had some experience with Arduino, so I was familiar with basic electronics and simple sensor logic, but ESP32 was still a new environment for me.

Instead of directly jumping into large projects, I wanted to understand how each component works on its own first. Because of that, this repository became a collection of small experiments and learning projects.

Some of the things I worked on here:

* OLED display communication
* LED control
* potentiometer input reading
* buzzer testing
* basic warning system logic
* GPIO and analog input usage

Most of the projects were developed in simulation environments while I was learning the ESP32 workflow step by step.

The main purpose of this repository is not to build perfect projects, but to document the learning process and improve my understanding of embedded systems over time.

I’m especially interested in aviation-inspired embedded systems, sensor-based projects and real-time control systems, so many of these small tests are connected to ideas I want to develop further in the future.
